# Team Docs

Use this directory for all team-related documentation.

This directory should mirror the TeamCode directory at TeamCode/src/main/java/org/firstinspires/ftc/teamcode/

> ex. if you have a program at TeamCode/src/main/java/org/firstinspires/ftc/teamcode/teleop/MyTeleopProgram.java, you should have a corresponding documentation file at TeamDocs/teleop/MyTeleopProgram.md describing its behavior

Some files are included in the root of this directory for general repo documentation that should only be updated through the FtcRobotControllerTemplate repository.
